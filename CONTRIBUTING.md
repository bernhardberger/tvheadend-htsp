# Contributing

Read `AGENTS.md` and the authority index in `docs/README.md` before editing.
Preserve the exact five-package protocol boundary, public typed-outcome policy,
generated-source evidence, attribution, and Kotlin/Java ABI checks. Production
and test behavior changes require a focused failing regression test first.

Do not add publication, signing, release, Android, Media3, native, application,
or consumer-resolution machinery as incidental standalone-library work.
