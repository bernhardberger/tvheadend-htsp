# API reference branding

Dokka applies these files to the HTML API reference, which ships as the javadoc
jar and is published on javadoc.io. The configuration is the
`pluginsConfiguration.html` block in the root `build.gradle.kts`.

| File | Role |
|---|---|
| `tvheadend-htsp.css` | Brand colours and the Outfit title font over Dokka's theme variables |
| `logo-styles.css` | Replaces Dokka's file of the same name to size the header logo |
| `logo-icon.svg` | Replaces Dokka's header logo |
| `Outfit-550.ttf`, `Outfit-OFL.txt` | Title font and its license, shipped together |

The palette, symbol and font come from the
[Tvheadend Player](https://github.com/bernhardberger/tvheadend-player) brand,
described in its `artwork/README.md`. The copies are unmodified, taken at player
commit `1ac38ebd6b5c35b5a1fa1e4d0e4c74ce96cb1a07`:

| File | Player source | SHA-256 |
|---|---|---|
| `logo-icon.svg` | `artwork/tvheadend-player-symbol.svg` (GPL-3.0, generated by `tools/RenderArtwork.java`) | `8ed0b5cd8edf050f731904554123a18bb278f00fc1027c729640e9e192bda53a` |
| `Outfit-550.ttf` | `artwork/fonts/Outfit-550.ttf` (SIL OFL 1.1, Copyright 2021 The Outfit Project Authors) | `727366fc010a90ad71c0f639ddc85336c175bb5074041311e2b863960d6ecf46` |
| `Outfit-OFL.txt` | `artwork/fonts/OFL.txt` | `c676351bf8576b9aba743cd5eaa8c0e7ee0d51f805d720447b4df4ddb6a2e416` |

To change the artwork, regenerate it in the player repository and copy it here
again; do not edit the copies. Keep orange to the accent role it has in the
player: the logo's play symbol and the active-tab marker.
